## 1. 系统架构与拓扑

```
┌─────────────┐    Vite Dev(5173)      ┌──────────────────┐
│   浏览器     │ ──────────────────────▶ │  前端 (Vue3)     │
│ (localhost) │    /api 代理 → 3000     └──────────────────┘
└─────────────┘                                  │ /api 代理
                                                 ▼
                                        ┌──────────────────┐
                                        │  后端 (Express)  │  端口 3000
                                        │  Node.js + 内存  │
                                        │  mockDb          │
                                        └──────────────────┘
```

- **后端**：Node.js + Express，内存 mockDb（重启数据重置，预留 MySQL 扩展口）。
- **前端**：Vue3 + Vite + Element Plus + Pinia（持久化）。
- **联调**：前端 `vite.config.js` 已配置 `/api` 代理到 `http://localhost:3000`。

## 3. 快速启动（开发环境）

```powershell
# 1. 克隆仓库并切换到主分支
git clone https://gitee.com/new-new-yaya/hospital-message.git
cd hospital-message
git pull origin one-fourth

# 2. 配置环境变量（首次必做）
Copy-Item .env.example .env
# 编辑 .env，修改 JWT_SECRET 为随机长字符串（安全要求，见安全检测报告）

# 3. 安装后端依赖并启动（端口 3000）
npm install
npm run dev

# 4. 另开终端，安装前端依赖并启动（端口 5173）
cd his-frontend
npm install
npm run dev
```

浏览器打开 **http://localhost:5173**（自动跳转 `/login`），点右侧「演示账号」按钮自动填充。

> 注意：前端代码在 `feat/his-frontend-songyao` 分支，若 `one-fourth` 分支无 `his-frontend/` 目录，需先
> `git checkout feat/his-frontend-songyao -- his-frontend` 拉取前端代码。

## 5. 环境变量说明（.env）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | 3000 | 后端监听端口 |
| `JWT_SECRET` | dev_secret_please_change | JWT 签名密钥，**生产必须 ≥ 32 位随机串，否则服务拒绝启动** |

## 6. 生产环境部署

### 6.1 前端打包

```powershell
cd his-frontend
npm run build          # 产出 dist/ 静态文件
```

产物 `dist/` 可部署到 Nginx / 任意静态服务器。

### 6.2 后端进程守护（PM2）

```powershell
npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
pm2 startup            # 开机自启
```

常用运维命令：

```powershell
pm2 status              # 查看状态
pm2 logs his-backend    # 查看日志
pm2 restart his-backend
pm2 stop his-backend
```

> ⚠️ **重要**：因数据为内存存储，`ecosystem.config.js` 中 `instances: 1`（fork 单实例），
> 不能开 cluster 多实例（会导致数据不一致）。PM2 重启后数据自动重置，属设计约定。

### 6.3 Nginx 反向代理（可选）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        root  /path/to/his-frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反代
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 7. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 前端 5173 打开白屏 / 请求失败 | 后端未启动 | 先启动后端 `npm run dev`（端口 3000） |
| `npm` 命令报错（PowerShell 禁止运行脚本） | 执行策略限制 | 用 `npm.cmd` 替代 `npm`，或 `Set-ExecutionPolicy RemoteSigned` |
| 登录后一直提示"登录已失效" | `.env` 未配置或 token 过期 | 检查 `.env`，重新登录 |
| `npm run seed` 报"脚本不存在" | 项目无 seed 脚本 | 勿运行 seed；数据在 `src/models/mockDb.js` 内置 |
| `test-closed-loop.bat` 跑不通 | patient1 已有挂号触发防重规则 | 改用 patient11，或运行 `node task4/run-tests.js` |
| 重复挂号返回 400 | 同一患者已有候诊/就诊单 | 属正常业务校验，前端已提示 |
| `/api/admin/ui` 404 | 管理端演示页已删除 | 使用 `/api/admin/*` 接口或前端 AdminView |
