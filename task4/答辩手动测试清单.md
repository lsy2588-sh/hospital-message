# HIS 系统 答辩手动测试清单

> 准备：后端已启动（本地 `http://localhost:3000` 或公网 trycloudflare 地址）
> 工具：Apifox / Postman
> 演示账号：admin/admin123、patient11/patient123、patient1/patient123

---

## 场景一：低权限角色调管理接口（应 403）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | POST `/api/auth/login`，body `{"username":"patient11","password":"patient123"}`，复制返回的 token | 200，拿到 token |
| 2 | 新建 GET `/api/admin/users`，Header 加 `Authorization: Bearer <上一步token>` | **403 无权限访问** |
| 3 | 换 `doctor1/doctor123` 登录，GET `/api/admin/drugs` | **403** |
| 4 | 换 `cashier1/cashier123` 登录，GET `/api/admin/departments` | **403** |
| 5 | 用 `admin/admin123` 登录，GET `/api/admin/users` | **200**（对照：admin 可以） |

## 场景二：用户越权访问（患者A看患者B，应 403）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 登录 `patient2/patient123`，复制 token_A | 200 |
| 2 | GET `/api/registrations/reg01`，Header 用 token_A（reg01 属于 patient1） | **403 无权限访问** |
| 3 | 登录 `patient1/patient123`，复制 token_B，GET 同一 `/api/registrations/reg01` | **200**（对照：本人可看） |
| 4 | GET `/api/prescriptions/rx01`，Header 用 token_A（rx01 属于 patient4） | **403** |

## 场景三：查询审计日志（admin 专属）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 先重复场景一/二做几次越权（制造 403 记录） | - |
| 2 | 登录 `admin/admin123`，复制 token | 200 |
| 3 | GET `/api/admin/audit-logs`，Header 用 admin token | **200**，返回日志数组 |
| 4 | 观察日志字段：能看到刚才的 403 记录（`username`/`role`/`method`/`path`/`status_code`） | 记录里有 `patient11 ... /admin/users -> 403` 等 |
| 5 | 可选筛选：GET `/api/admin/audit-logs?username=patient11`、`?status_code=403`、`?limit=10` | 只返回符合条件 |
| 6 | 用 `patient11` 的 token 访问 `/api/admin/audit-logs` | **403**（审计日志只能 admin 看） |
